Delta Function¶

  • The Dirac delta function δ(x)\delta(x)δ(x) is a generalized function or distribution.

  • The Dirac delta function is commonly used in physics and engineering to represent idealized point sources or impulses.

  • When integrating over it and another function f(t)f(t)f(t), it "picks out" the value of the function at a specific point:

∫abf(t) δ(t−t0) dt=f(t0)for a<t0<b\int_a^b f(t) \, \delta(t - t_0) \, dt = f(t_0) \quad \text{for } a < t_0 < b∫ab​f(t)δ(t−t0​)dt=f(t0​)for a<t0​<b
(1)

This property indicates that the delta function evaluates a function f(t)f(t)f(t) at t=t0t = t_0t=t0​, and outside this interval, the integral is zero.

  • The delta function is normalized as follows:

∫−∞∞δ(x) dx=1\int_{-\infty}^{\infty} \delta(x) \, dx = 1∫−∞∞​δ(x)dx=1
(2)

Delta Function (continued)¶

  • While the delta function is not a proper function, it can be viewed as the limit of a family of normalized functions.

  • One common representation is in terms of a top-hat functions:

Πa(x)={1aif ∣x∣<a20otherwise\Pi_a(x) = \begin{cases} \frac{1}{a} & \text{if } |x| < \frac{a}{2} \\ 0 & \text{otherwise} \end{cases}Πa​(x)={a1​0​if ∣x∣<2a​otherwise​
(3)

  • Another common representation is in terms of a Gaussian. In the limit as a→0a \to 0a→0:

δa(x)=1∣a∣πe−x2/a2\delta_a(x) = \frac{1}{|a|\sqrt{\pi}} e^{-x^2/a^2}δa​(x)=∣a∣π​1​e−x2/a2
(4)

This approximation is useful in numerical analysis, where δ(x)\delta(x)δ(x) can be represented and manipulated as a limit of smooth functions.

  • Both of these functions satisfy the normalization condition:

∫−∞∞δa(x) dx=1\int_{-\infty}^{\infty} \delta_a(x) \, dx = 1∫−∞∞​δa​(x)dx=1
(5)

  • As a→0a \to 0a→0, these functions converge to the delta function: δ(x)=lim⁡a→0δa(x)\delta(x) = \lim_{a \to 0} \delta_a(x)δ(x)=lima→0​δa​(x)

Properties of the delta function¶

Green’s functions: Introduction¶

  • The Green’s function provides a powerful method for solving inhomogeneous linear equation systems.

  • The Green’s function generalizes the concept of an inverse matrix or an impulse response to continuous systems.

  • The Green’s function is fundamentally defined as the response of the linear system to a unit impulse.

  • Let’s write the linear equation system as Ly(x)=f(x)Ly(x)=f(x)Ly(x)=f(x), where f(x)f(x)f(x) represents the forcing term or input.

  • The Green’s function G(x,z)G(x,z)G(x,z) must satisfy the exact same homogeneous linear differential equation as y(x)y(x)y(x), but with the forcing term replaced by the Dirac delta function δ(x−z)\delta(x-z)δ(x−z):

LG(x,z)=δ(x−z)L G(x, z) = \delta(x-z)LG(x,z)=δ(x−z)
(6)

  • Physically, G(x,z)G(x,z)G(x,z) may be thought of as the response of the system at position xxx resulting from a unit-strength point source located at position zzz.

Green’s functions: Introduction (continued)¶

  • Once the Green’s function is known, the solution y(x)y(x)y(x) to the original inhomogeneous system Ly(x)=f(x)Ly(x)=f(x)Ly(x)=f(x) is found by integrating the forcing term fff against the Green’s function G(x,z)G(x,z)G(x,z):

y(x)=∫abG(x,z)f(z)dzy(x) = \int_{a}^{b} G(x, z) f(z) dzy(x)=∫ab​G(x,z)f(z)dz
(7)

  • This integral means that the response of the system to a distributed force f(x)f(x)f(x) is the superposition of the individual responses (GGG) to infinitesimal impulses comprising f(x)f(x)f(x).

  • In linear systems, the solution to forced dynamics is given by the convolution of the input (forcing) with the system’s impulse response. The integral form above shows that the Green’s function serves as the impulse response function g(t)g(t)g(t) generalized to differential operators.

  • In case of the linear differential operator LLL, the solution is formally y=L−1fy=L^{-1}fy=L−1f. The Green’s function G(x,z)G(x,z)G(x,z) is the kernel that defines this inverse linear operator L−1L^{-1}L−1 through integration.

Driving force¶

  • Let’s consider an inhomogeneous linear equation:

Dy(t)=f(t)D y(t) = f(t)Dy(t)=f(t)
(8)

DDD is a linear operator that represents any linear ordinary differential equation (ODE).

  • f(t)f(t)f(t) represents some driving force acting on the system. We can view it as a sum of delta functions:

f(t)=∑iciδ(t−ti)f(t) = \sum_i c_i \delta(t - t_i)f(t)=i∑​ci​δ(t−ti​)
(9)

  • In continuous form, this becomes

f(t)=∫0∞f(t′)δ(t′−t) dt′f(t) = \int_0^\infty f(t') \delta(t' - t) \, dt'f(t)=∫0∞​f(t′)δ(t′−t)dt′
(10)

  • This representation implies that f(t)f(t)f(t) can be thought of as a sum of "kicks" applied to the system at different times. If we find the response of the system to one of these kicks, then we can just sum up all of these responses for each kick to get the total response. This is the idea of the Green’s function.

Green’s function definition¶

  • Next, we define the Green’s function as the solution to the ODE with a delta function as the source term.

  • The Green’s function G(t,t′)G(t, t')G(t,t′) satisfies:

Dy(t)=f(t)D y(t) = f(t)Dy(t)=f(t)
(11)
DG(t,t′)=δ(t−t′)D G(t, t') = \delta(t - t')DG(t,t′)=δ(t−t′)
(12)
y(t)=∫0tG(t,t′)f(t′) dt′y(t) = \int_0^t G(t, t') f(t') \, dt'y(t)=∫0t​G(t,t′)f(t′)dt′
(13)

  • The Green’s function G(t,t′)G(t, t')G(t,t′) represents the system’s response to a delta function "kick" applied at time t′t't′.

  • The solution y(t)y(t)y(t) to the original differential equation can be written as a convolution of the source term f(t′)f(t')f(t′) with the Green’s function G(t,t′)G(t, t')G(t,t′).

Proof for the Green’s function¶

  • We can verify the equation y(t)=∫0tG(t,t′)f(t′) dt′y(t) = \int_0^t G(t, t') f(t') \, dt'y(t)=∫0t​G(t,t′)f(t′)dt′ is a solution by substituting it back into the original ODE Dy(t)=f(t)D y(t) = f(t)Dy(t)=f(t):

Dy(t)=D(∫0tG(t,t′)f(t′) dt′)D y(t) = D \left( \int_0^t G(t, t') f(t') \, dt' \right)Dy(t)=D(∫0t​G(t,t′)f(t′)dt′)
(14)

  • Since DDD is a linear operator that operates on ttt, it can be applied inside the integral:

Dy(t)=∫0t(DG(t,t′))f(t′) dt′D y(t) = \int_0^t (D G(t, t')) f(t') \, dt'Dy(t)=∫0t​(DG(t,t′))f(t′)dt′
(15)

  • By definition, the Green’s function G(t,t′)G(t, t')G(t,t′) satisfies the following equation:

DG(t,t′)=δ(t−t′)D G(t, t') = \delta(t - t')DG(t,t′)=δ(t−t′)
(16)

  • Substituting this back into the expression for Dy(t)D y(t)Dy(t):

Dy(t)=∫0tδ(t−t′)f(t′) dt′=f(t)D y(t) = \int_0^t \delta(t - t') f(t') \, dt' = f(t)Dy(t)=∫0t​δ(t−t′)f(t′)dt′=f(t)
(17)

Proof for the Green’s function (continued)¶

Dy(t)=∫0tδ(t−t′)f(t′) dt′=f(t)D y(t) = \int_0^t \delta(t - t') f(t') \, dt' = f(t)Dy(t)=∫0t​δ(t−t′)f(t′)dt′=f(t)
(18)

  • This confirms that y(t)y(t)y(t) satisfies the original inhomogeneous equation, proving that the convolution of the Green’s function with the source term f(t′)f(t')f(t′) is indeed the solution for any linear differential operator DDD.

  • Consider the driven damped harmonic oscillator:

y′′(t)+2γy′(t)+ω02y(t)=f(t)y''(t) + 2\gamma y'(t) + \omega_0^2 y(t) = f(t)y′′(t)+2γy′(t)+ω02​y(t)=f(t)

  • The Laplace transform of the differential equation yields:

Example: Driven damped harmonic oscillator (continued)¶

  • Using the Green’s function, the general solution to the original equation is given by:

y(t)=∫0tG(t,t′)f(t′) dt′y(t) = \int_0^t G(t, t') f(t') \, dt'y(t)=∫0t​G(t,t′)f(t′)dt′

  • This solution shows that the system’s response at time ttt is a sum of the responses to the source term f(t′)f(t')f(t′) at all previous times t′t't′, weighted by the Green’s function. The Green’s function incorporates both the damping and the oscillatory nature of the harmonic oscillator.

System of linear equations¶

  • Let’s try to solve matrix equation
