Backpropagation¶

The [backpropagation]{style=“color: blue”} algorithm ([backprop]{style=“color: blue”}) exploits the compositional nature of NNs in order to frame an optimization problem for determining the weights of the network.

Input-output relationship for this single node, one hidden layer network:

y=g(z,b)=g(f(x,a),b)y=g(z,b) = g(f(x,a), b)y=g(z,b)=g(f(x,a),b)
(14)

f(⋅)f(\cdot)f(⋅) and g(⋅)g(\cdot)g(⋅) are activation functions,
aaa and bbb are weighting constants.

Loss function¶

Input-output relationship: y=g(z,b)=g(f(x,a),b)y=g(z,b) = g(f(x,a), b)y=g(z,b)=g(f(x,a),b)

Let’s set the output error as

E=1/2(y0−y)2,E = 1/2 (y_0-y)^2,E=1/2(y0​−y)2,
(15)

  • y0y_0y0​ - correct output

  • yyy - NN approximation to the output

  • aaa, bbb needs to be optimized to minimize the error

Minimization condition:

∂E∂a=−(y0−y)dydzdzda=0\frac{\partial E}{\partial a} =- (y_0-y) \frac{d y}{d z} \frac{dz}{da} = 0∂a∂E​=−(y0​−y)dzdy​dadz​=0
(16)

The compositional nature of the network along with the chain rule forces the optimization to backpropagate error through the network.

Backpropagation algorithm¶

Backprop results in an iterative, gradient descent update rule:

ak+1=ak+δ∂E∂aka_{k+1} = a_k + \delta \frac{\partial E}{\partial a_k}ak+1​=ak​+δ∂ak​∂E​
(17)
bk+1=bk+δ∂E∂bkb_{k+1} = b_k + \delta \frac{\partial E}{\partial b_k}bk+1​=bk​+δ∂bk​∂E​
(18)

δ\deltaδ is the [learning rate]{style=“color: blue”}.

Backdrop algorithm:

  1. NN is specified along with a labeled training set.

  2. The initial weights of the network are set to random values (not zeros!)

  3. The training data is run through the network to produce an output yyy. The derivatives with respect to each network weight are then computed using backprop formulas.

  4. The network weights are updated using a given δ\deltaδ.

  5. Go to step 3, repeat until convergence.

Example: Backpropagation for linear activation function¶

Consider linear activation function:

f(ξ,α)=g(ξ,α)=αξf(\xi, \alpha) = g(\xi, \alpha) = \alpha \xif(ξ,α)=g(ξ,α)=αξ
(19)

Then we have

z=axz = axz=ax
(20)
y=bzy = bzy=bz
(21)

Gradients:

∂E∂a=−(y0−y)dydzdzda=−(y0−y)⋅b⋅x\frac{\partial E}{\partial a} =- (y_0-y) \frac{d y}{d z} \frac{dz}{da} = -(y_0-y) \cdot b \cdot x∂a∂E​=−(y0​−y)dzdy​dadz​=−(y0​−y)⋅b⋅x
(22)
∂E∂b=−(y0−y)dydb=−(y0−y)z=−(y0−y)⋅a⋅x\frac{\partial E}{\partial b} =- (y_0-y) \frac{d y}{d b} = -(y_0-y) z = -(y_0-y) \cdot a \cdot x∂b∂E​=−(y0​−y)dbdy​=−(y0​−y)z=−(y0​−y)⋅a⋅x
(23)

Knowing xxx, yyy, and current aaa, bbb, we can evaluate each derivative and update aaa and bbb.

Backpropagation (continued)¶

For a network with M hidden layers z1z_1z1​ to zmz_mzm​ and the first connection weight aaa between xxx and z1z_1z1​, the gradient looks like:

∂E∂a=−(y0−y)dydzmdzmdzm−1⋯dz2dz1dz1da\frac{\partial E}{\partial a} =- (y_0-y) \frac{d y}{d z_m} \frac{dz_m}{dz_{m-1}} \cdots \frac{dz_2}{dz_{1}} \frac{dz_1}{da}∂a∂E​=−(y0​−y)dzm​dy​dzm−1​dzm​​⋯dz1​dz2​​dadz1​​
(24)

Update step:

wk+1=wk+δ∇E,\mathbf{w}_{k+1} = \mathbf{w}_k + \delta \nabla E,wk+1​=wk​+δ∇E,
(25)

where vector w\mathbf{w}w contains all the elements of the matrices Aj\mathbf{A}_jAj​.
In component form, for jjj component of vector w\mathbf{w}w:

wk+1j=wkj+δ∂E∂wkjw_{k+1}^j = w_k^j + \delta \frac{\partial E}{\partial w_k^j}wk+1j​=wkj​+δ∂wkj​∂E​

Curse of dimensionality: Computational cost to train NN might be unfeasible: for NN with nnn-dimensional input, updating weights for each layer is ∼n2\sim n^2∼n2!

Gradient descent¶

The aim of the gradient decent is to find a minimum of E given its parameters Aj\mathbf{A}_jAj​. I.e., the objective function is:

argminAjE(A1,A2,…,AM)\text{argmin}_{\mathbf{A}_j} E(\mathbf{A}_1, \mathbf{A}_2, \dots, \mathbf{A}_M)argminAj​​E(A1​,A2​,…,AM​)
(27)

For a NN, Aj\mathbf{A}_jAj​ are the connectivity matrices between the layers:

f(x)=f(x,A1,A2,…,AM)f(\mathbf{x}) = f(\mathbf{x}, \mathbf{A}_1, \mathbf{A}_2, \dots, \mathbf{A}_M)f(x)=f(x,A1​,A2​,…,AM​)
(28)

The goal of training the NN is to minimize the error between the network and the data. The standard root-mean square error is then:

argminAjE(A1,A2,…,AM)=argminAj∑k=1n(f(x,A1,A2,AM)−yk)2\text{argmin}_{\mathbf{A}_j} E(\mathbf{A}_1, \mathbf{A}_2, \dots, \mathbf{A}_M) = \text{argmin}_{\mathbf{A}_j} \sum_{k=1}^n ( f(\mathbf{x}, \mathbf{A}_1, \mathbf{A}_2, \mathbf{A}_M) - \mathbf{y}_k)^2argminAj​​E(A1​,A2​,…,AM​)=argminAj​​k=1∑n​(f(x,A1​,A2​,AM​)−yk​)2
(29)

Gradient descent:

xj+1(δ)=xj−δ∇f(xj),\mathbf{x}_{j+1} (\delta) = \mathbf{x}_{j} - \delta \nabla f(\mathbf{x}_j),xj+1​(δ)=xj​−δ∇f(xj​),
(30)

where δ\deltaδ is the learning rate.

Stochastic gradient descent¶

Error sum over all data:

E(A1,A2,…,AM)=∑k=1nEk(A1,A2,…,AM),E(\mathbf{A}_1, \mathbf{A}_2, \dots, \mathbf{A}_M) = \sum_{k=1}^n E_k (\mathbf{A}_1, \mathbf{A}_2, \dots, \mathbf{A}_M),E(A1​,A2​,…,AM​)=k=1∑n​Ek​(A1​,A2​,…,AM​),
(31)

where EkE_kEk​ is the error of each data point kkk (the whole training set includes nnn points).

Ek(A1,A2,…,AM)=(fk(xk,A1,A2,AM)−yk)2E_k (\mathbf{A}_1, \mathbf{A}_2, \dots, \mathbf{A}_M) = ( f_k(\mathbf{x_k}, \mathbf{A}_1, \mathbf{A}_2, \mathbf{A}_M) - \mathbf{y}_k)^2Ek​(A1​,A2​,…,AM​)=(fk​(xk​,A1​,A2​,AM​)−yk​)2
(32)

Here, fkf_kfk​ is the fitting function for each data point.
[Stochastic gradient descent:]{style=“color: blue”}

wj+1(δ)=wj−δ∇fk(wj)\mathbf{w}_{j+1}(\delta) = \mathbf{w}_j - \delta \nabla f_k(\mathbf{w}_j)wj+1​(δ)=wj​−δ∇fk​(wj​)
(33)

Here, we use wj\mathbf{w}_jwj​ (the vector of all the network weights at jjjth iteration) but a single kkkth data point and fkf_kfk​.

Stochastic gradient descent (continued)¶

Pros:

  • computational cost!

  • Using different points and varying the number of points at each iteration helps to avoid getting stuck in local minima.

Cons:

  • multiple passes are needed to find a global minimum.

Using [batch]{style=“color: blue”} (several data points): K∈[k1,k2,…,kp]K \in [k_1, k_2, \dots, k_p]K∈[k1​,k2​,…,kp​]
