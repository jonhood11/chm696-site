Learning goals¶

By the end of this lecture, you should be able to:

  • express a feed-forward neural network as a composition of affine maps and activation functions;

  • explain why nonlinear activations are essential for expressive deep models;

  • use the chain rule to derive a simple backpropagation gradient; and

  • distinguish full-batch, stochastic, and mini-batch gradient descent.

Backpropagation¶

The [backpropagation]{style=“color: blue”} algorithm ([backprop]{style=“color: blue”}) exploits the compositional nature of NNs in order to frame an optimization problem for determining the weights of the network.

What the original figure plots. It shows computational graph for a two-stage scalar neural network.

What this is trying to convey. Backpropagation applies the chain rule from the loss backward through this computational graph.

Polished version.

Input-output relationship for this single node, one hidden layer network:

y=g(z,b)=g(f(x,a),b)y=g(z,b) = g(f(x,a), b)y=g(z,b)=g(f(x,a),b)
(14)

f(⋅)f(\cdot)f(⋅) and g(⋅)g(\cdot)g(⋅) are activation functions,
aaa and bbb are weighting constants.

Loss function¶

Input-output relationship: y=g(z,b)=g(f(x,a),b)y=g(z,b) = g(f(x,a), b)y=g(z,b)=g(f(x,a),b)

For a target value y0y_0y0​, define the squared-error loss

E=12(y0−y)2.E = \frac{1}{2}(y_0-y)^2.E=21​(y0​−y)2.
(15)

  • y0y_0y0​ - correct output

  • yyy - NN approximation to the output

  • aaa and bbb are optimized to reduce the error

The chain rule gives

∂E∂a=−(y0−y)dydzdzda.\frac{\partial E}{\partial a} =-(y_0-y)\frac{dy}{dz}\frac{dz}{da}.∂a∂E​=−(y0​−y)dzdy​dadz​.
(16)

The derivative need not be zero during training. Backpropagation efficiently evaluates these chain-rule derivatives; an optimizer then uses them to update the parameters.

Backpropagation algorithm¶

Backprop results in an iterative, gradient descent update rule:

ak+1=ak−η∂E∂a∣ak,bka_{k+1} = a_k - \eta \left.\frac{\partial E}{\partial a}\right|_{a_k,b_k}ak+1​=ak​−η∂a∂E​∣∣​ak​,bk​​
(17)
bk+1=bk−η∂E∂b∣ak,bkb_{k+1} = b_k - \eta \left.\frac{\partial E}{\partial b}\right|_{a_k,b_k}bk+1​=bk​−η∂b∂E​∣∣​ak​,bk​​
(18)

η>0\eta>0η>0 is the [learning rate]{style=“color: blue”}.

Backpropagation training loop:

  1. NN is specified along with a labeled training set.

  2. The initial weights of the network are set to random values (not zeros!)

  3. The training data is run through the network to produce an output yyy. The derivatives with respect to each network weight are then computed using backprop formulas.

  4. The optimizer updates the weights using the gradients and learning rate.

  5. Go to step 3, repeat until convergence.

Gradient descent¶

The aim of gradient descent is to reduce the training objective as a function of all network parameters:

minimize⁡Θ  E(Θ).\underset{\Theta}{\operatorname{minimize}}\;E(\Theta).Θminimize​E(Θ).
(27)

For a NN, Aj\mathbf{A}_jAj​ are the connectivity matrices between the layers:

f(x)=f(x,A1,A2,…,AM)f(\mathbf{x}) = f(\mathbf{x}, \mathbf{A}_1, \mathbf{A}_2, \dots, \mathbf{A}_M)f(x)=f(x,A1​,A2​,…,AM​)
(28)

For a squared-error regression model, one possible objective is the mean squared error

E(Θ)=1n∑k=1n∥F(xk;Θ)−yk∥22.E(\Theta) =\frac{1}{n}\sum_{k=1}^n \left\lVert F(\mathbf{x}_k;\Theta)-\mathbf{y}_k\right\rVert_2^2.E(Θ)=n1​k=1∑n​∥F(xk​;Θ)−yk​∥22​.
(29)

Gradient descent:

Θt+1=Θt−η∇ΘE(Θt),\Theta_{t+1}=\Theta_t-\eta\nabla_\Theta E(\Theta_t),Θt+1​=Θt​−η∇Θ​E(Θt​),
(30)

where η\etaη is the learning rate.

Stochastic gradient descent¶

Error sum over all data:

E(Θ)=1n∑k=1nEk(Θ),E(\Theta) = \frac{1}{n}\sum_{k=1}^n E_k(\Theta),E(Θ)=n1​k=1∑n​Ek​(Θ),

where EkE_kEk​ is the error of each data point kkk (the whole training set includes nnn points).

Ek(Θ)=∥F(xk;Θ)−yk∥22.E_k(\Theta) =\left\lVert F(\mathbf{x}_k;\Theta)-\mathbf{y}_k\right\rVert_2^2.Ek​(Θ)=∥F(xk​;Θ)−yk​∥22​.

Stochastic gradient descent (continued)¶

Pros:

  • each update is inexpensive and can begin before evaluating the whole data set

  • noisy gradients can help optimization move through flat regions and shallow local basins

Cons:

  • the updates are noisy and usually require learning-rate scheduling and multiple passes; convergence to a global minimum is not guaranteed

Using a [mini-batch]{style=“color: blue”} BtB_tBt​ of several observations:
