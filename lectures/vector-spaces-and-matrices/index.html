Learning goals¶

After this lecture, you should be able to:

  • state the defining axioms of a vector space;

  • distinguish span, linear independence, basis, and dimension;

  • use inner products, norms, and orthogonality correctly;

  • represent a linear map as a matrix after choosing bases; and

  • check dimensions and compute matrix-vector and matrix-matrix products.

Vector spaces¶

  • In mathematics and physics, a vector space (also called a linear space) is a set whose elements, aka vectors, can be added together and multiplied ("scaled") by numbers called scalars.

  • The operations of vector addition and scalar multiplication must satisfy certain requirements, called vector axioms.

  • Vector spaces are characterized by their dimension, which, roughly speaking, specifies the number of independent directions in the space.

Axioms of Vector Spaces¶

The axioms to be satisfied for every a\mathbf{a}a, b\mathbf{b}b, and c\mathbf{c}c in vector space V , and λ\lambdaλ and μ\muμ in scalar field F:

  • Associativity of vector addition: a+(b+c)=(a+b)+c\mathbf{a}+ (\mathbf{b}+ \mathbf{c}) = (\mathbf{a}+ \mathbf{b}) + \mathbf{c}a+(b+c)=(a+b)+c

  • Commutativity of vector addition: a+b=b+a\mathbf{a}+ \mathbf{b}= \mathbf{b}+ \mathbf{a}a+b=b+a

  • Identity element of vector addition: There exists an element 0∈V\mathbf{0} \in V0∈V, called the zero vector, such that a+0=a\mathbf{a}+ \mathbf{0} = \mathbf{a}a+0=a for all a∈V\mathbf{a}\in Va∈V.

  • Inverse elements of vector addition: For every a∈V\mathbf{a}\in Va∈V, there exists −a∈V-\mathbf{a}\in V−a∈V such that a+(−a)=0\mathbf{a}+(-\mathbf{a})=\mathbf 0a+(−a)=0.

  • Compatibility of scalar multiplication with field multiplication: λ(μa)=(λμ)a\lambda(\mu \mathbf{a}) = (\lambda \mu)\mathbf{a}λ(μa)=(λμ)a

  • Identity element of scalar multiplication: 1a=a1 \mathbf{a}= \mathbf{a}1a=a, where 1 denotes the multiplicative identity in F.

  • Distributivity of scalar multiplication with respect to vector addition: λ(a+b)=λa+λb\lambda(\mathbf{a}+ \mathbf{b}) = \lambda \mathbf{a}+ \lambda \mathbf{b}λ(a+b)=λa+λb.

  • Distributivity of scalar multiplication with respect to field addition: (λ+μ)a=λa+μa(\lambda + \mu) \mathbf{a}= \lambda \mathbf{a}+ \mu \mathbf{a}(λ+μ)a=λa+μa.

Linear Dependence of Vectors¶

  • Two vectors v1\mathbf{v}_1v1​ and v2\mathbf{v}_2v2​ are linearly independent if c1v1+c2v2=0c_1\mathbf{v}_1+c_2\mathbf{v}_2=\mathbf 0c1​v1​+c2​v2​=0 implies c1=c2=0c_1=c_2=0c1​=c2​=0.

  • If such scalars exist, the vectors are linearly dependent.

  • Geometrically, this is just saying that the vectors v1\mathbf{v_1}v1​ and v2\mathbf{v_2}v2​ are linearly independent if they do not lie along the same line.

  • This means we cannot express one as a multiple of the other.

  • For N-dimensional space, vectors are linearly dependent if there is a set of scalars (not simultaneously zero) such that c1v1+c2v2+⋯+cnvn=0c_1\mathbf{v_1} + c_2\mathbf{v_2} + \cdots +c_n\mathbf{v_n} =0c1​v1​+c2​v2​+⋯+cn​vn​=0.

Basis vectors¶

  • If V is an N-dimensional vector space, then any set of N linearly independent vectors e1,e2,...,eN\mathbf{e}_1,\mathbf{e}_2, ..., \mathbf{e}_Ne1​,e2​,...,eN​ forms a basis for V.

  • If x\mathbf{x}x is an arbitrary vector in V, then the set of N+1N +1N+1 vectors x,e1,e2,⋯ ,eN\mathbf{x} , \mathbf{e}_1, \mathbf{e}_2, \cdots , \mathbf{e}_Nx,e1​,e2​,⋯,eN​, must be linearly dependent, i.e., αe1+βe2+⋯+σeN+ξx=0\alpha \mathbf{e}_1 +\beta \mathbf{e}_2 + \cdots + \sigma \mathbf{e}_N + \xi \mathbf{x} = 0αe1​+βe2​+⋯+σeN​+ξx=0, where ξ≠0\xi \neq 0ξ=0.

  • Then we can rearrange this as: x=(−α/ξ)e1+(−β/ξ)e2+⋯+(−σ/ξ)eN=∑i=1Nxiei\mathbf{x} = (-\alpha /\xi) \mathbf{e}_1 + (- \beta /\xi) \mathbf{e}_2 + \cdots + (-\sigma /\xi) \mathbf{e}_N = \sum _{i=1}^N x_i \mathbf{e}_ix=(−α/ξ)e1​+(−β/ξ)e2​+⋯+(−σ/ξ)eN​=∑i=1N​xi​ei​

  • Since any x\mathbf{x}x lying in the span of V can be expressed in terms of the basis or base vectors ei\mathbf{e}_iei​, the latter are said to form a complete set.

  • The components xix_ixi​ of x\mathbf{x}x with respect to the ei\mathbf{e}_iei​ basis are unique.

  • In a different set ei′\mathbf{e}'_iei′​, the same (!!!) x\mathbf{x}x can be written as: x=x1′e1′+x2′e2′+⋯+xN′eN′=∑i=1Nxi′ei′\mathbf{x} = x'_1 \mathbf{e}'_1 + x'_2 \mathbf{e}'_2 + \cdots + x'_N \mathbf{e}'_N = \sum _{i=1}^N x'_i \mathbf{e}'_ix=x1′​e1′​+x2′​e2′​+⋯+xN′​eN′​=∑i=1N​xi′​ei′​

The Inner Product¶

  • The inner product of vectors ⟨a∣b⟩\langle \mathbf{a}| \mathbf{b}\rangle⟨a∣b⟩

  • The inner product is a generalization of the dot product to abstract vector spaces.

Properties of the inner product

  • ⟨a∣b⟩=⟨b∣a⟩∗\langle \mathbf{a}| \mathbf{b}\rangle = \langle \mathbf{b}| \mathbf{a}\rangle^*⟨a∣b⟩=⟨b∣a⟩∗

  • ⟨a∣λb+μc⟩=λ⟨a∣b⟩+μ⟨a∣c⟩\langle \mathbf{a}| \lambda \mathbf{b}+ \mu \mathbf{c}\rangle = \lambda \langle \mathbf{a}| \mathbf{b}\rangle + \mu \langle \mathbf{a}|\mathbf{c}\rangle⟨a∣λb+μc⟩=λ⟨a∣b⟩+μ⟨a∣c⟩

  • Conjugate linearity in the first argument: ⟨λa+μb∣c⟩=λ∗⟨a∣c⟩+μ∗⟨b∣c⟩\langle \lambda\mathbf{a}+\mu\mathbf{b}|\mathbf{c}\rangle =\lambda^*\langle\mathbf{a}|\mathbf{c}\rangle +\mu^*\langle\mathbf{b}|\mathbf{c}\rangle⟨λa+μb∣c⟩=λ∗⟨a∣c⟩+μ∗⟨b∣c⟩.

  • And ⟨λa∣μb⟩=λ∗μ⟨a∣b⟩\langle \lambda \mathbf{a}| \mu \mathbf{b}\rangle = \lambda^* \mu \langle \mathbf{a}| \mathbf{b}\rangle⟨λa∣μb⟩=λ∗μ⟨a∣b⟩

Vectors are orthogonal if ⟨a∣b⟩=0\langle \mathbf{a}| \mathbf{b}\rangle = 0⟨a∣b⟩=0

Norm of the vector is ∣∣a∣∣=⟨a∣a⟩1/2|| \mathbf{a}|| = \langle \mathbf{a}| \mathbf{a}\rangle ^{1/2}∣∣a∣∣=⟨a∣a⟩1/2

Linear operators¶

  • In mathematics, an operator is generally a mapping or function that acts on elements of a space to produce elements of another space (possibly and sometimes required to be the same space).

  • A linear operator is a linear transformation between vector spaces (or a vector space and itself). For example, a linear operator A\mathcal{A}A associates with every vector x\mathbf{x}x another vector y=Ax\mathbf{y} = \mathcal{A} \mathbf{x}y=Ax

  • Linear operator satisfies properties of additivity (or superposition) and homogeneity: A(λa+μb)=λAa+μAb\mathcal{A} (\lambda \mathbf{a} + \mu \mathbf{b}) = \lambda \mathcal{A} \mathbf{a} + \mu \mathcal{A}\mathbf{b}A(λa+μb)=λAa+μAb

  • The action of A\mathcal{A}A is independent of any basis or coordinate system!

Matrix elements of a linear operator¶

Let’s introduce the basis ei,  i=1,2,…,N\mathbf{e}_i, \; i = 1,2, \dots, Nei​,i=1,2,…,N

  • The action of linear operator A\mathcal{A}A on each of the basis vectors is to produce a linear combination of them: Aej=∑i=1NAijei\mathcal{A}\mathbf{e}_j = \sum_{i=1}^N A_{ij} \mathbf{e}_iAej​=∑i=1N​Aij​ei​

  • AijA_{ij}Aij​ is the iiith component of the vector Aej\mathcal{A}\mathbf{e}_jAej​ in this basis.

  • Collectively, the numbers AijA_{ij}Aij​ are called the components of the linear operator in the ei\mathbf{e}_iei​-basis.

  • y=Ax\mathbf{y} = \mathcal{A} \mathbf{x}y=Ax becomes (in this basis!!!): y=∑i=1Nyiei=A(∑j=1Nxjej)=∑j=1Nxj∑i=1NAijei\mathbf{y} = \sum_{i=1}^N y_i \mathbf{e}_i = \mathcal{A} \left( \sum_{j=1}^N x_j \mathbf{e}_j \right) = \sum_{j=1}^N x_j \sum_{i=1}^N A_{ij} \mathbf{e}_iy=∑i=1N​yi​ei​=A(∑j=1N​xj​ej​)=∑j=1N​xj​∑i=1N​Aij​ei​

  • In purely component form, in this basis we have: yi=∑j=1NAijxjy_i = \sum_{j=1}^N A_{ij} x_jyi​=∑j=1N​Aij​xj​

  • Note: in a different basis (in which components of x\mathbf{x}x, y\mathbf{y}y, A\mathcal{A}A are xi′x'_ixi′​, yi′y'_iyi′​, Aij′A'_{ij}Aij′​, respectively) y=Ax\mathbf{y} = \mathcal{A} \mathbf{x}y=Ax becomes yi′=∑j=1NAij′xj′y'_i = \sum_{j=1}^N A'_{ij} x'_jyi′​=∑j=1N​Aij′​xj′​

  • In general, y\mathbf{y}y and x\mathbf{x}x might belong to different vector spaces, i.e., x\mathbf{x}x is in N-dimensional space, and y\mathbf{y}y in M-dimensional space. Then introduce the basis for y\mathbf{y}y space: fi\mathbf{f}_ifi​, i=1,2,...,M. Then, Aej=∑i=1MAijfi\mathcal{A}\mathbf{e}_j = \sum_{i=1}^M A_{ij} \mathbf{f}_iAej​=∑i=1M​Aij​fi​, where components AijA_{ij}Aij​ relate both to bases ei\mathbf{e}_iei​ and fi\mathbf{f}_ifi​.

Properties of linear operators¶

Given: x\mathbf{x}x is a vector, A\mathcal{A}A and B\mathcal{B}B are linear operators

  • (A+B)x=Ax+Bx(\mathcal{A} + \mathcal{B} )\mathbf{x} =\mathcal{A}\mathbf{x} + \mathcal{B}\mathbf{x}(A+B)x=Ax+Bx

  • (λA)x=λ(Ax)(\lambda \mathcal{A} )\mathbf{x} = \lambda (\mathcal{A} \mathbf{x})(λA)x=λ(Ax)

  • (AB)x=A(Bx)(\mathcal{A} \mathcal{B} )\mathbf{x} =\mathcal{A} (\mathcal{B}\mathbf{x})(AB)x=A(Bx) - action of linear operators is associative

  • However, the product of linear operators is in general not commutative: ABx≠BAx\mathcal{A} \mathcal{B} \mathbf{x} \neq \mathcal{B} \mathcal{A} \mathbf{x}ABx=BAx

  • Null operator: Ox=0\mathcal{O} \mathbf{x} = \mathbf{0}Ox=0

  • Identity operator: Ix=x\mathcal{I} \mathbf{x} = \mathbf{x}Ix=x

  • Operators are equal if Ax=Bx\mathcal{A} \mathbf{x} = \mathcal{B} \mathbf{x}Ax=Bx for all vectors x\mathbf{x}x

  • A−1\mathcal{A}^{-1}A−1 is inverse of A\mathcal{A}A: AA−1=A−1A=I\mathcal{A} \mathcal{A}^{-1} = \mathcal{A}^{-1} \mathcal{A} = \mathcal{I}AA−1=A−1A=I

  • The linear operators that do not possess an inverse are called singular, whilst those operators that do have an inverse are termed non-singular.

Matrices¶

  • We saw that vectors and linear operators can be described in terms of their components with respect to a basis. These components may be displayed as an array of numbers called a matrix.

  • If a linear operator A\mathcal{A}A transforms vectors from an N-dimensional vector space (with basis ei\mathbf{e}_iei​, i=1,2,..., N) into vectors belonging to an M-dimensional vector space (with basis fi\mathbf{f}_ifi​, i=1,2,..., M), it can be represented by the M×NM \times NM×N matrix:

A=(A11A12…A1NA21A22…A2N⋮⋮⋱⋮AM1AM2…AMN)A = \begin{pmatrix} A_{11} & A_{12} & \dots & A_{1N}\\ A_{21} & A_{22} & \dots & A_{2N}\\ \vdots & \vdots & \ddots & \vdots\\ A_{M1} & A_{M2} & \dots & A_{MN} \end{pmatrix}A=⎝⎛​A11​A21​⋮AM1​​A12​A22​⋮AM2​​……⋱…​A1N​A2N​⋮AMN​​⎠⎞​
(3)

  • If the dimensions of the two vector spaces are the same, i.e. M = N (for example, if they are the same vector space) then we may represent A\mathcal{A}A by an N × N or square matrix of order N.

Vector as a column matrix¶

  • We may denote a vector x\mathbf{x}x in terms of its components xix_ixi​ in a basis ei\mathbf{e}_iei​, i = 1,2,..., N, as

x=(x1x2⋮xN)\mathbf{x} = \begin{pmatrix} x_1 \\ x_2 \\ \vdots \\ x_N \end{pmatrix}x=⎝⎛​x1​x2​⋮xN​​⎠⎞​
(4)

  • This is called a column matrix or a column vector.

  • Alternative notation as a transpose or a row matrix: x=(x1  x2  ⋯xN)T\text{x} = (x_1 \; x_2 \; \cdots x_N)^Tx=(x1​x2​⋯xN​)T

  • Note (again!) that the same vector in a different basis will be represented by a different matrix, i.e., x′=(x1′  x2′  ⋯xN′)T\text{x}' = (x'_1 \; x'_2 \; \cdots x'_N)^Tx′=(x1′​x2′​⋯xN′​)T

Multiplication of matrices - cont¶

  • For P=AB\mathbf P=\mathbf A\mathbf BP=AB to be defined, if A\mathbf AA is M×NM\times NM×N, then B\mathbf BB must be N×RN\times RN×R. The product is M×RM\times RM×R.

Span, basis, and dimension¶

The same act of taking linear combinations produces a line from one direction and a plane from two independent directions. This connects span directly to dimension.

fig = plt.figure(figsize=(10, 4.8))
ax1 = fig.add_subplot(1, 2, 1, projection="3d")
t = np.linspace(-2, 2, 100)
v = np.array([1.0, 0.55, 0.3])
line = t[:, None] * v
ax1.plot(*line.T, color=DARK_GOLD, linewidth=3)
ax1.quiver(0, 0, 0, *v, color=BLACK, arrow_length_ratio=0.12)
ax1.set(title="One independent vector spans a line",
        xlabel="$x$", ylabel="$y$", zlabel="$z$")

ax2 = fig.add_subplot(1, 2, 2, projection="3d")

s, t2 = np.meshgrid(np.linspace(-1.3, 1.3, 12), np.linspace(-1.3, 1.3, 12))

A matrix maps the unit circle to an ellipse¶

The image of a circle shows, in one picture, how a linear map stretches, rotates, and mixes directions while still preserving straight lines.

A = np.array([[1.7, 0.8], [0.25, 0.75]])
theta = np.linspace(0, 2*np.pi, 500)
circle = np.vstack([np.cos(theta), np.sin(theta)])
ellipse = A @ circle

fig, axes = plt.subplots(1, 2, figsize=(9.4, 4.3))
for ax, points, title in [(axes[0], circle, "input vectors"),
                          (axes[1], ellipse, "output vectors A x")]:
    ax.plot(points[0], points[1], color=DARK_GOLD, linewidth=2.5)
    for angle in np.linspace(0, 2*np.pi, 12, endpoint=False):
        source = np.array([np.cos(angle), np.sin(angle)])
        endpoint = source if ax is axes[0] else A @ source
        ax.plot([0, endpoint[0]], [0, endpoint[1]], color=GRAY, alpha=0.5)
    ax.axhline(0, color=BLACK, linewidth=0.8)
    ax.axvline(0, color=BLACK, linewidth=0.8)
    ax.set(aspect="equal", xlim=(-2.7,2.7), ylim=(-2.1,2.1),
           xlabel="$x_1$", ylabel="$x_2$", title=title)
fig.suptitle("A linear transformation acts on every direction at once")
fig.tight_layout()
plt.show()

Matrix multiplication as composition¶

The three panels enforce the order of operations: BBB acts first, followed by AAA. The product ABABAB is the single transformation with the same final result.

A = np.array([[1.0, -0.45], [0.35, 1.0]])
B = np.array([[1.5, 0.0], [0.0, 0.65]])
shape = np.array([[0,0], [1.6,0], [0.4,1.2]])
stages = [shape, shape @ B.T, shape @ B.T @ A.T]
titles = ["x", "B x", "A(B x) = (AB)x"]

fig, axes = plt.subplots(1, 3, figsize=(11, 3.9), sharex=True, sharey=True)
for ax, vertices, title in zip(axes, stages, titles):
    ax.add_patch(Polygon(vertices, closed=True, facecolor=GOLD,
                         edgecolor=DARK_GOLD, linewidth=2, alpha=0.6))
    ax.scatter(vertices[:,0], vertices[:,1], color=BLACK, s=28, zorder=3)
    ax.axhline(0, color=GRAY, linewidth=0.8)
    ax.axvline(0, color=GRAY, linewidth=0.8)
    ax.set(aspect="equal", xlim=(-1,2.8), ylim=(-0.5,2.2), title=title)
fig.suptitle("The rightmost matrix acts first")
fig.tight_layout()

One vector in two orthonormal bases¶

The physical vector does not change when the basis changes; only its component column changes. This distinguishes a vector from its coordinates.

angle = np.deg2rad(32)
Q = np.array([[np.cos(angle), -np.sin(angle)],
              [np.sin(angle),  np.cos(angle)]])
v = np.array([2.8, 1.9])
coordinates = Q.T @ v

fig, axes = plt.subplots(1, 2, figsize=(9.6, 4.4), sharex=True, sharey=True)
for ax, basis, comps, title in [
    (axes[0], np.eye(2), v, rf"standard components = ({v[0]:.1f}, {v[1]:.1f})"),
    (axes[1], Q, coordinates,
     rf"rotated-basis components = ({coordinates[0]:.2f}, {coordinates[1]:.2f})"),
]:
    ax.quiver(0, 0, *v, angles="xy", scale_units="xy", scale=1,
              color=BLACK, width=0.014)
    for j, color in zip(range(2), [DARK_GOLD, GOLD]):
        ax.quiver(0, 0, *basis[:,j], angles="xy", scale_units="xy", scale=1,
                  color=color, width=0.012)
        ax.text(*(1.18*basis[:,j]), f"e{j+1}'" if ax is axes[1] else f"e{j+1}")
    ax.set(aspect="equal", xlim=(-1.2,3.6), ylim=(-0.8,3.2),
           xlabel="$x$", ylabel="$y$", title=title)
fig.suptitle("The arrow is unchanged; its coordinates depend on the basis")
fig.tight_layout()
plt.show()

ChatGPT-assisted extensions¶

For any of these assignments, students may use ChatGPT as a provisional collaborator, but the submission must include the important prompts, an independent mathematical check, at least one correction or limitation, and the student’s own conceptual explanation. ChatGPT output by itself is not evidence.

  1. Vector-space courtroom. Ask ChatGPT to generate unusual proposed vector spaces: polynomials with restrictions, probability vectors, functions, matrices, or sets with modified addition. For three examples, either verify the axioms or identify the first axiom that fails with a concrete counterexample. Explain why closure alone is not enough.

  2. Same object, different coordinates. Represent one polynomial, function, or physical vector in two different bases. Ask ChatGPT to derive the change-of-basis matrix, then verify it by reconstructing the same object from both component columns. Include a diagram or numerical check showing that the object is unchanged although its coordinates differ.

  3. Linear-transformation detective. Give ChatGPT several input-output pairs and ask it to infer a matrix. Decide which observations are sufficient for a unique answer, reconstruct the matrix when possible, and create one nonlinear impostor that matches the supplied examples but fails linearity elsewhere. Explain why testing only a few vectors can be misleading.
