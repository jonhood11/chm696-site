Optimization problems¶

  • Derivative-free methods

    • Nelder--Mead (Simplex method): Works with a set of points forming a simplex, updates by reflection/expansion/contraction. Good for low-dimensional problems.

    • Powell’s Method: Searches along directions iteratively, doesn’t require derivatives.

    • Pattern Search / Coordinate Descent: Updates one coordinate or direction at a time.

  • Gradient-Based Methods

    • Gradient Descent: Iteratively updates xk+1=xk−α∇f(xk)x_{k+1} = x_k - \alpha \nabla f(x_k)xk+1​=xk​−α∇f(xk​) where α\alphaα is the step size (learning rate).

    • Newton’s Method: Uses the Hessian (second derivative matrix) for faster (quadratic) convergence: xk+1=xk−H−1(xk)∇f(xk)x_{k+1} = x_k - H^{-1}(x_k) \nabla f(x_k)xk+1​=xk​−H−1(xk​)∇f(xk​). More expensive (needs Hessian), but very powerful.

    • Quasi-Newton Methods (e.g., BFGS, L-BFGS): Approximate the Hessian cheaply; widely used in optimization libraries.

    • Conjugate Gradient (CG): Efficient for large-scale quadratic problems; uses gradient info but builds conjugate directions instead of computing Hessians.

Optimization problems (continued)¶

  • Constrained Optimization: for problems with constraints g(x)≤0,  h(x)=0.g(x) \le 0, \; h(x) = 0.g(x)≤0,h(x)=0.

    • Lagrange Multipliers: Convert constrained problem to unconstrained one with multipliers.

    • Penalty and Barrier Methods: Incorporate constraints into the objective via extra terms.

  • Global Optimization: for functions with many local minima.

    • Simulated Annealing: Inspired by physics annealing, uses probabilistic jumps to escape local minima.

    • Genetic Algorithms / Evolutionary Strategies: Population-based search mimicking evolution.

    • Particle Swarm Optimization: Inspired by swarm intelligence (birds, fish).

    • Bayesian Optimization: Builds a probabilistic model (e.g., Gaussian processes) to guide exploration.

  • Specialized Methods

    • Linear Programming: Simplex method, Interior-point methods.

    • Stochastic Gradient Descent (SGD): Very popular in machine learning (updates on minibatches of data).

Linear system of equations as optimization problem¶

The system Ax=bA \mathbf{x} = \mathbf{b}Ax=b can be recast as a quadratic optimization problem. Define:

f(x)=12xTAx−xTb.f(\mathbf{x}) = \frac{1}{2} \mathbf{x}^T A \mathbf{x} - \mathbf{x}^T \mathbf{b}.f(x)=21​xTAx−xTb.
(1)

Key properties of f(x)f(\mathbf{x})f(x):

  • It is a convex quadratic function (if AAA is symmetric and positive definite).

  • The gradient of f(x)f(\mathbf{x})f(x) is:

∇f(x)=Ax−b.\nabla f(\mathbf{x}) = A \mathbf{x} - \mathbf{b}.∇f(x)=Ax−b.
(2)

  • The minimum of f(x)f(\mathbf{x})f(x) satisfies:

∇f(x)=0  ⟹  Ax=b.\nabla f(\mathbf{x}) = 0 \implies A \mathbf{x} = \mathbf{b}.∇f(x)=0⟹Ax=b.
(3)

Gradient Descent Method¶

Gradient descent is an iterative optimization algorithm used to minimize a function f(x)f(x)f(x).

The key idea is to move in the opposite direction of the gradient, since the gradient points toward increasing values.

For an objective function f:Rn→Rf:\mathbb{R}^n \to \mathbb{R}f:Rn→R, starting from an initial guess x0x_0x0​:

xk+1=xk−α ∇f(xk)x_{k+1} = x_k - \alpha \, \nabla f(x_k)xk+1​=xk​−α∇f(xk​)
(4)

where

  • xkx_kxk​: current point,

  • ∇f(xk)\nabla f(x_k)∇f(xk​): gradient at the current point,

  • α>0\alpha > 0α>0: learning rate (step size).

Repeat until ∥∇f(xk)∥<ϵ\|\nabla f(\mathbf{x}_k)\| < \epsilon∥∇f(xk​)∥<ϵ, where ϵ\epsilonϵ is a small tolerance.
Intuition:\

  • If α\alphaα is too small, convergence is slow.

  • If α\alphaα is too large, the algorithm may overshoot and diverge.

Steepest Descent Method¶

  • This is a more general version of the gradient descent.

  • We still make the step in the direction opposite to the gradient: xk+1=xk−α ∇f(xk)x_{k+1} = x_k - \alpha \, \nabla f(x_k)xk+1​=xk​−α∇f(xk​).

  • However, α\alphaα is chosen via a line search (minimizing along the chosen direction).

  • This approach guarantees to find the minimum!

  • However, it might be slow; suffers from zig-zags.

Conjugate Gradient (CG) method¶

The Conjugate Gradient (CG) method improves upon the Gradient Descent by ensuring that each step is taken in a direction that is conjugate (with respect to AAA) to the previous steps.

Note

Key Requirements The CG method applies to systems where:

  • AAA is symmetric (AT=AA^T = AAT=A).

  • AAA is positive definite (xTAx>0\mathbf{x}^T A \mathbf{x} > 0xTAx>0).

Note

Conjugacy and AAA-Orthogonality

Two vectors pi\mathbf{p}_ipi​ and pj\mathbf{p}_jpj​ are [AAA-orthogonal (conjugate)]{style=“color: blue”} if:

piTApj=0for i≠j.\mathbf{p}_i^T A \mathbf{p}_j = 0 \quad \text{for } i \neq j.piT​Apj​=0for i=j.
(5)

Picking conjugate directions ensures that movement along one direction does not “undo” progress made along previous ones.

Conjugacy and A A A-Orthogonality¶

Conjugacy and AAA-Orthogonality

Geometrical intuition:\

  • As we assume, ∇f(x)=Ax−b\nabla f(\mathbf{x}) = A \mathbf{x} - \mathbf{b}∇f(x)=Ax−b.

  • How does the gradient change when we move along some direction?: δ(∇f(x))=A⋅(δx)\delta (\nabla f(\mathbf{x})) = A \cdot (\delta\mathbf{x})δ(∇f(x))=A⋅(δx)

  • Note that if we minimize a function along some direction u\mathbf{u}u, the gradient of the function must be perpendicular to u\mathbf{u}u at the line minimum. If not, then there would still be a nonzero directional derivative along u\mathbf{u}u.

  • Suppose we have moved along u\mathbf{u}u to a minimum and now propose to move along some new direction v\mathbf{v}v. The condition that motion along v\mathbf{v}v not spoil minimization along u\mathbf{u}u is that the gradient stay perpendicular to u\mathbf{u}u, i.e., the change in the gradient is perpendicular to u\mathbf{u}u: 0=uT⋅δ(∇f(x))=uT⋅A⋅v0 = \mathbf{u}^T \cdot \delta (\nabla f(\mathbf{x})) = \mathbf{u}^T \cdot A \cdot \mathbf{v}0=uT⋅δ(∇f(x))=uT⋅A⋅v

    1. Start with an initial guess x0\mathbf{x}_0x0​.

    For k=0,1,…,n−1k = 0, 1, \dots, n-1k=0,1,…,n−1:

αk=rkTrkpkTApk\alpha_k = \frac{\mathbf{r}_k^T \mathbf{r}_k}{\mathbf{p}_k^T A \mathbf{p}_k}αk​=pkT​Apk​rkT​rk​​

Functional Minimization and Taylor Expansion¶

The CG method minimizes the quadratic function:

f(x)=12xTAx−bTx.f(\mathbf{x}) = \frac{1}{2} \mathbf{x}^T A \mathbf{x} - \mathbf{b}^T \mathbf{x}.f(x)=21​xTAx−bTx.

Using the Taylor series expansion:

f(x+Δx)=f(x)+∇f(x)TΔx+12ΔxTAΔx.f(\mathbf{x} + \Delta \mathbf{x}) = f(\mathbf{x}) + \nabla f(\mathbf{x})^T \Delta \mathbf{x} + \frac{1}{2} \Delta \mathbf{x}^T A \Delta \mathbf{x}.f(x+Δx)=f(x)+∇f(x)TΔx+21​ΔxTAΔx.

Conjugate Gradient (CG) for solving linear systems of equations¶

  • Cost per iteration

    • Matrix-vector multiplication:
      O(N2)O(N^2)O(N2) for dense N×NN \times NN×N matrices.
      If AAA is sparse with MMM nonzero entries: O(M)O(M)O(M).

    • updates: Cost: O(N)O(N)O(N)

    • Inner products: Cost: O(N)O(N)O(N)

  • Number of iterations:

    • In exact arithmetic, CG converges in at most NNN iterations for an N×NN \times NN×N system.

    • In practice, convergence depends on the condition number of AAA: κ(A)=λmax⁡λmin⁡\kappa(A) = \frac{\lambda_{\max}}{\lambda_{\min}}κ(A)=λmin​λmax​​, with rough estimate of iterations to reach accuracy ϵ\epsilonϵ: k≲κ(A) log⁡1ϵ.k \lesssim \sqrt{\kappa(A)} \, \log \frac{1}{\epsilon}.k≲κ(A)​logϵ1​.

  • Memory cost

    • CG requires storing only a few vectors of size NNN (residuals, search directions, solution)

    • Direct methods (LU, Gaussian elimination) require O(N2)O(N^2)O(N2) memory for dense matrices

Newton’s Method¶

Newton’s Method

  • Newton’s Method uses the Hessian (second derivative matrix) for faster (quadratic) convergence.

  • More expensive (needs Hessian), but very powerful.

  • Consider (again!) the Taylor series expansion f(x+Δx)=f(x)+∇f(x)TΔx+12ΔxTAΔx.f(\mathbf{x} + \Delta \mathbf{x}) = f(\mathbf{x}) + \nabla f(\mathbf{x})^T \Delta \mathbf{x} + \frac{1}{2} \Delta \mathbf{x}^T A \Delta \mathbf{x}.f(x+Δx)=f(x)+∇f(x)TΔx+21​ΔxTAΔx.

  • We are looking for the stationary point, i.e., dfdx=0\frac{df}{d\mathbf{x}} = 0dxdf​=0.

  • This results in: ∇f(x)+ΔxTA=0⇒Δx=−∇f(x)A−1\nabla f(\mathbf{x}) + \Delta \mathbf{x}^T A = 0\Rightarrow \Delta \mathbf{x} = -\nabla f(\mathbf{x}) A^{-1}∇f(x)+ΔxTA=0⇒Δx=−∇f(x)A−1

  • In other words, xk+1=xk−H−1(xk)∇f(xk)x_{k+1} = x_k - H^{-1}(x_k) \nabla f(x_k)xk+1​=xk​−H−1(xk​)∇f(xk​), where HHH is the Hessian (matrix of function’s second derivatives).

  • Intuition: think of 1D harmonic oscillator. We would need a larger geometry displacement if the gradient is larger or the force constant is smaller.

  • The step is exact in the case of a quadratic function and exact gradient and Hessian.

Quasi-Newton Method¶

  • Computing and inverting HkH_kHk​ can be expensive for large nnn.

  • The idea of the Pseudo-Newton (Quasi-Newton) method is to approximate the Hessian HkH_kHk​ by a matrix Bk≈HkB_k \approx H_kBk​≈Hk​ or its inverse.

  • The update becomes

xk+1=xk−Bk ∇f(xk),\mathbf{x}_{k+1} = \mathbf{x}_k - B_k \, \nabla f(\mathbf{x}_k),xk+1​=xk​−Bk​∇f(xk​),
(10)

where BkB_kBk​ is a computationally cheaper approximation of the inverse Hessian. The method uses gradient information from previous iterations to improve BkB_kBk​ step by step.

  • To ensure BkB_kBk​ captures curvature information, we enforce the secant (quasi-Newton) condition Bk+1yk=sk,B_{k+1} \mathbf{y}_k = \mathbf{s}_k,Bk+1​yk​=sk​, where sk=xk+1−xk,yk=∇f(xk+1)−∇f(xk).\mathbf{s}_k = \mathbf{x}_{k+1} - \mathbf{x}_k, \quad \mathbf{y}_k = \nabla f(\mathbf{x}_{k+1}) - \nabla f(\mathbf{x}_k).sk​=xk+1​−xk​,yk​=∇f(xk+1​)−∇f(xk​). This condition ensures the new Hessian approximation matches the observed change in gradients along the last step.

Both formulas maintain symmetry and positive-definiteness of BkB_kBk​, which is important for convergence.

Quasi-Newton Method (continued)¶

Key points:\

  • Pseudo-Newton is faster than gradient descent because it incorporates curvature information.

  • It is cheaper than Newton’s method because it avoids computing the Hessian.

  • The method achieves superlinear convergence for smooth functions if the line search is accurate.

  • Only gradients are required, not second derivatives.

  • It is suitable for medium-scale problems (hundreds to thousands of variables).
