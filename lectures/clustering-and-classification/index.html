Feature selection and data mining¶

  • The goal of data mining and machine learning is to construct and exploit the intrinsic low-rank feature space of a given data set.

  • Sometimes the feature space can be found in an unsupervised fashion by an algorithm like PCA.

  • Sometimes the feature space can be explicitly constructed by expert knowledge and/or correlations among the data.

Supervised versus unsupervised learning¶

Original-slide figure pending review

The original lecture refers to supervised_vs_unsupervised.png. The file is preserved in the private Overleaf archive and will be redrawn or published after its reuse rights are verified.

[Supervised]{style=“color: blue”} learning: the training data is labeled by a teacher/expert/supervisor. The model is used for prediction and classification of new data.
[Unsupervised]{style=“color: blue”} learning: no training labels are given. The goal itself may be to discover patterns in the data so that feature engineering or feature extraction can be used to build an appropriate model.

Unsupervised learning: k-means clustering¶

Original-slide figure pending review

The original lecture refers to k-means.png. The file is preserved in the private Overleaf archive and will be redrawn or published after its reuse rights are verified.

  1. Given initial values for k distinct means, compute the distance of each observation xj\mathbf{x}_jxj​ to each of the k means.

  2. Label each observation as belonging to the nearest mean.

  3. Once labeling is completed, find the center-of-mass (mean) for each group of labeled points. These new means are used to start back at step 1 in the algorithm.

Unsupervised learning: k-means clustering (continued)¶

This process is described by the following minimization process:

argminμj∑j=1k∑xj∈Dj′∣∣xj−μj∣∣2,\text{argmin}_{\mu_j} \sum_{j=1}^{k} \sum_{\mathbf{x}_j \in D_j'} ||\mathbf{x}_j - \mu_j||^2,argminμj​​j=1∑k​xj​∈Dj′​∑​∣∣xj​−μj​∣∣2,
(8)

where μj\mu_jμj​ is the mean of the jth cluster, Dj′D_j'Dj′​ is the subdomain of data associated with that cluster.

Unsupervised hierarchical clustering¶

  • [Agglomerative]{style=“color: blue”}: bottom-up approach. Each data point xj\mathbf{x}_jxj​ is its own cluster initially. The data is merged in pairs as one creates a hierarchy of clusters.

  • [Divisive]{style=“color: blue”}: top-down approach. All the observations xj\mathbf{x}_jxj​ are initially part of a single giant cluster. The data is then recursively split into smaller and smaller clusters.

The results of hierarchical clustering might dramatically depend on distance metrics:

  • Euclidean distance ∣∣xj−xk∣∣2|| \mathbf{x}_j - \mathbf{x}_k||_2∣∣xj​−xk​∣∣2​

  • Squared euclidean distance ∣∣xj−xk∣∣22|| \mathbf{x}_j - \mathbf{x}_k||_2^2∣∣xj​−xk​∣∣22​

  • Manhattan distance ∣∣xj−xk∣∣1|| \mathbf{x}_j - \mathbf{x}_k||_1∣∣xj​−xk​∣∣1​

  • Maximum distance ∣∣xj−xk∣∣∞|| \mathbf{x}_j - \mathbf{x}_k||_\infty∣∣xj​−xk​∣∣∞​

  • Mahalanobis distance (xj−xk)TC−1(xj−xk)\sqrt{(\mathbf{x}_j - \mathbf{x}_k)^T C^{-1} (\mathbf{x}_j - \mathbf{x}_k) }(xj​−xk​)TC−1(xj​−xk​)​

Unsupervised learning: Finite mixture models¶

The fundamental assumption of the mixture model is that the probability density function (PDF) for observations of data xj\mathbf{x}_jxj​ is a weighted linear sum of a set of unknown distributions:

f(xj,Θ)=∑p=1kαpfp(xj,Θp)f(\mathbf{x}_j, \Theta) = \sum_{p=1}^k \alpha_p f_p(\mathbf{x}_j, \Theta_p)f(xj​,Θ)=p=1∑k​αp​fp​(xj​,Θp​)
(9)

fff is the measured PDF,
fpf_pfp​ is the PDF of the mixture j,
kkk is the total number of mixtures.
PDFs fjf_jfj​ are weighted by αp\alpha_pαp​ (α1+α2+⋯+αk=1\alpha_1 + \alpha_2 + \dots + \alpha_k =1α1​+α2​+⋯+αk​=1) and parametrized by an unknown vector of parameters Θp\Theta_pΘp​.

Objective: Given the observed PDF f(xj,Θ)f(\mathbf{x}_j, \Theta)f(xj​,Θ), estimate the mixture weights αp\alpha_pαp​ and the parameters of the distribution Θp\Theta_pΘp​.
User input: the number of mixtures kkk and the individual statistical properties of each mixture.

Gaussian mixture models (GMM)¶

Gaussian mixture model (GMM) assumption: each mixture model Θp\Theta_pΘp​ has a Gaussian distribution, i.e., it can be completely characterized by the mean μp\mu_pμp​ and the variance σp\sigma_pσp​.

f(xj,Θ)=∑p=1kαpNp(xj,μp,σp)f(\mathbf{x}_j, \Theta) = \sum_{p=1}^k \alpha_p N_p (\mathbf{x}_j, \mu_p, \sigma_p)f(xj​,Θ)=p=1∑k​αp​Np​(xj​,μp​,σp​)
(10)

Maximum likelihood estimate (MLE)¶

An estimate of the parameter vector Θ\ThetaΘ can be computed using the maximum likelihood estimate (MLE):

∂L(Θ)∂Θ=0\frac{\partial L(\Theta)}{\partial \Theta} = 0∂Θ∂L(Θ)​=0
(11)

Log-likelihood function LLL:

L(Θ)=∑j=1nlog⁡f(xj∣Θ)L(\Theta) = \sum_{j=1}^n \log f(\mathbf{x}_j |\Theta)L(Θ)=j=1∑n​logf(xj​∣Θ)
(12)

Linear discriminant analysis¶

The goal of LDA: find a suitable projection that maximizes the distance between the inter-class data while minimizing the distance between intra-class data.

Between-class variance:

SB=(μ2−μ1)(μ2−μ1)TS_B = (\mu_2 - \mu_1)(\mu_2 - \mu_1)^TSB​=(μ2​−μ1​)(μ2​−μ1​)T
(17)

Within-class variance:

SW=∑j=12∑x(x−μj)(x−μj)TS_W = \sum_{j=1}^2 \sum_{\mathbf{x}} (\mathbf{x} - \mu_j)(\mathbf{x} - \mu_j)^TSW​=j=1∑2​x∑​(x−μj​)(x−μj​)T
(18)

Objective: find a projection:

w=arg maxwwTSBwwTSWw\mathbf{w} = \text{arg max}_\mathbf{w} \frac{\mathbf{w}^T S_B \mathbf{w} }{\mathbf{w} ^T S_W \mathbf{w} }w=arg maxw​wTSW​wwTSB​w​
(19)

This is the generalized Rayleigh quotient that can be solved via the generalized eigenvalue problem SBw=λSWwS_B \mathbf{w} = \lambda S_W \mathbf{w}SB​w=λSW​w
