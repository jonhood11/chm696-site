# CHM 696 public-site instructions

- This repository is a public deployment target. Treat every committed file as
  public and student-visible.
- Do not add instructor notes, solutions, unreleased assessments, student
  information, grades, credentials, or private correspondence.
- Authoritative course planning and private source belong in the sibling private
  `CHM696` repository.
- Read `_STATE.md` before publication work and update it only with public-safe
  deployment facts.
- Distinguish a prepared build from a committed, pushed, and live deployment.
