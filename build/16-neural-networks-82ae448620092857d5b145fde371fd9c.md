Weights: $\mathbf{A}_i$\

## Linear and nonlinear mappings


- Linear mapping: 3-layer network $$\mathbf{x}^{(1)} = \mathbf{A}_1 \mathbf{x}$$ $$\mathbf{x}^{(2)} = \mathbf{A}_2 \mathbf{x}^{(1)}$$ $$\mathbf{y} = \mathbf{A}_2 \mathbf{x}^{(2)}$$ $$\mathbf{y} = \mathbf{A}_3 \mathbf{A}_2 \mathbf{A}_1 \mathbf{x}$$ General M-layer network: $$\mathbf{y} = \mathbf{A}_M \mathbf{A}_{M-1} \dots \mathbf{A}_2 \mathbf{A}_1 \mathbf{x}$$ This is generally a highly underdetermined system.

- Nonlinear mapping $$\mathbf{x}^{(1)} = f_1(\mathbf{A}_1 \mathbf{x})$$ $$\mathbf{x}^{(2)} = f_2 (\mathbf{A}_2 \mathbf{x}^{(1)})$$ $$\mathbf{y} = f_3 (\mathbf{A}_2 \mathbf{x}^{(2)})$$ General M-layer network: $$\mathbf{y} = f_M (\mathbf{A}_M, \dots , f_2 (\mathbf{A}_2, f_1 (\mathbf{A}_1 \mathbf{x}) \dots )$$

## Non-linear mapping

Nonlinear transformation $$\mathbf{y} = f (\mathbf{A}, \mathbf{x})$$ $f(\cdot)$ is an [activation]{style="color: blue"} or [transfer]{style="color: blue"} function.

Common activation functions:

- $f(x) = x$ - linear

- $f(x) = \biggl\{ \; \begin{matrix}  0 \; \; \;  x \le 0 \\
      1 \; \; \;  x > 0
      \end{matrix}$ - binary step

- $f(x) = \frac{1}{1+\exp(-x)}$ - logistic (soft step)

- $f(x) = \tanh (x)$ - TanH

- $f(x) = \biggl\{ \; \begin{matrix}  0 \; \; \;  x \le 0 \\
      x \; \; \;  x > 0
      \end{matrix}$ - rectified linear unit (ReLU)

## Backpropagation

The [backpropagation]{style="color: blue"} algorithm ([backprop]{style="color: blue"}) exploits the compositional nature of NNs in order to frame an optimization problem for determining the weights of the network.


:::{note} Original-slide figure pending review
The original lecture refers to `backprop.png`. The file is preserved in the private Overleaf archive and will be redrawn or published after its reuse rights are verified.
:::

Input-output relationship for this single node, one hidden layer network: $$y=g(z,b) = g(f(x,a), b)$$

$f(\cdot)$ and $g(\cdot)$ are activation functions,\
$a$ and $b$ are weighting constants.


## Loss function

Input-output relationship: $y=g(z,b) = g(f(x,a), b)$

Let's set the output error as $$E = 1/2 (y_0-y)^2,$$

- $y_0$ - correct output

- $y$ - NN approximation to the output

- $a$, $b$ needs to be optimized to minimize the error

Minimization condition: $$\frac{\partial E}{\partial a} =- (y_0-y) \frac{d y}{d z} \frac{dz}{da} = 0$$

The compositional nature of the network along with the chain rule forces the optimization to *backpropagate error* through the network.


## Backpropagation algorithm

Backprop results in an iterative, gradient descent update rule: $$a_{k+1} = a_k + \delta \frac{\partial E}{\partial a_k}$$ $$b_{k+1} = b_k + \delta \frac{\partial E}{\partial b_k}$$

$\delta$ is the [learning rate]{style="color: blue"}.

Backdrop algorithm:

1.  NN is specified along with a labeled training set.

2.  The initial weights of the network are set to random values (not zeros!)

3.  The training data is run through the network to produce an output $y$. The derivatives with respect to each network weight are then computed using backprop formulas.

4.  The network weights are updated using a given $\delta$.

5.  Go to step 3, repeat until convergence.


## Example: Backpropagation for linear activation function

Consider linear activation function: $$f(\xi, \alpha) = g(\xi, \alpha) = \alpha \xi$$ Then we have $$z = ax$$ $$y = bz$$ Gradients: $$\frac{\partial E}{\partial a} =- (y_0-y) \frac{d y}{d z} \frac{dz}{da} = -(y_0-y) \cdot b \cdot x$$ $$\frac{\partial E}{\partial b} =- (y_0-y) \frac{d y}{d b} = -(y_0-y) z = -(y_0-y) \cdot a \cdot x$$

Knowing $x$, $y$, and current $a$, $b$, we can evaluate each derivative and update $a$ and $b$.


## Backpropagation (continued)

For a network with M hidden layers $z_1$ to $z_m$ and the first connection weight $a$ between $x$ and $z_1$, the gradient looks like: $$\frac{\partial E}{\partial a} =- (y_0-y) \frac{d y}{d z_m} \frac{dz_m}{dz_{m-1}} \cdots \frac{dz_2}{dz_{1}} \frac{dz_1}{da}$$ Update step: $$\mathbf{w}_{k+1} = \mathbf{w}_k + \delta \nabla E,$$ where vector $\mathbf{w}$ contains all the elements of the matrices $\mathbf{A}_j$.\
In component form, for $j$ component of vector $\mathbf{w}$: $$w_{k+1}^j = w_k^j + \delta \frac{\partial E}{\partial w_k^j}$$

**Curse of dimensionality**: Computational cost to train NN might be unfeasible: for NN with $n$-dimensional input, updating weights for each layer is $\sim n^2$!


## Gradient descent

The aim of the gradient decent is to find a minimum of E given its parameters $\mathbf{A}_j$. I.e., the objective function is: $$\text{argmin}_{\mathbf{A}_j} E(\mathbf{A}_1, \mathbf{A}_2, \dots, \mathbf{A}_M)$$

For a NN, $\mathbf{A}_j$ are the connectivity matrices between the layers: $$f(\mathbf{x}) = f(\mathbf{x}, \mathbf{A}_1, \mathbf{A}_2, \dots, \mathbf{A}_M)$$

The goal of training the NN is to minimize the error between the network and the data. The standard root-mean square error is then: $$\text{argmin}_{\mathbf{A}_j} E(\mathbf{A}_1, \mathbf{A}_2, \dots, \mathbf{A}_M) =  \text{argmin}_{\mathbf{A}_j} \sum_{k=1}^n ( f(\mathbf{x}, \mathbf{A}_1, \mathbf{A}_2, \mathbf{A}_M) - \mathbf{y}_k)^2$$

Gradient descent: $$\mathbf{x}_{j+1} (\delta) = \mathbf{x}_{j} - \delta \nabla f(\mathbf{x}_j),$$ where $\delta$ is the learning rate.


## Stochastic gradient descent

Error sum over all data: $$E(\mathbf{A}_1, \mathbf{A}_2, \dots, \mathbf{A}_M) = \sum_{k=1}^n E_k (\mathbf{A}_1, \mathbf{A}_2, \dots, \mathbf{A}_M),$$ where $E_k$ is the error of each data point $k$ (the whole training set includes $n$ points). $$E_k (\mathbf{A}_1, \mathbf{A}_2, \dots, \mathbf{A}_M) = ( f_k(\mathbf{x_k}, \mathbf{A}_1, \mathbf{A}_2, \mathbf{A}_M) - \mathbf{y}_k)^2$$ Here, $f_k$ is the fitting function for each data point.\
[Stochastic gradient descent:]{style="color: blue"} $$\mathbf{w}_{j+1}(\delta) = \mathbf{w}_j - \delta \nabla f_k(\mathbf{w}_j)$$ Here, we use $\mathbf{w}_j$ (the vector of all the network weights at $j$th iteration) but a **single** $k$th data point and $f_k$.


## Stochastic gradient descent (continued)

Pros:

- computational cost!

- Using different points and varying the number of points at each iteration helps to avoid getting stuck in local minima.

Cons:

- multiple passes are needed to find a global minimum.

Using [batch]{style="color: blue"} (several data points): $K \in [k_1, k_2, \dots, k_p]$ $$\mathbf{w}_{j+1}(\delta) = \mathbf{w}_j - \delta \nabla f_K(\mathbf{w}_j)$$
