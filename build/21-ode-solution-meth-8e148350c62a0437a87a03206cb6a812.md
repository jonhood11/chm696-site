## Linear First-Order Ordinary Differential Equations


- The most general **first-order linear ODE**:
```{math}
\frac{dy}{dx} + P(x)y = Q(x)
```


- Here, $y$ is the unknown function, $P(x)$ and $Q(x)$ are functions of $x$ but not of $y$. $Q(x)$ is the drive term.

- Note that in general we could also multiply $y'$ by a new function of $x$, but we could divide through by that function and absorb it into $P(x)$ and $Q(x)$.

- We will be looking for a solution in the form of
```{math}
y(x) = C y_h(x) + y_p(x)
```


  - $C$ is an arbitrary constant determined by the initial conditions

  - $y_h(x)$ is the homogeneous solution that does not depend on the drive

  - $y_p(x)$ is the particular solution to the inhomogeneous equation with drive


## Inhomogeneous Equation

The general solution to the inhomogeneous ODE can be broken down into two components:

- **Solution to the homogeneous equation**:
```{math}
y_h(x) = C e^{-\int P(x) dx}
```
 This is the solution to the homogeneous equation. It contains a constant that is determined by the boundary conditions. It does not depend on the drive $Q(x)$.

- **Particular solution (no constant)**:
```{math}
y_p(x) = e^{-\int P(x) dx} \int e^{\int P(x) dx} Q(x) dx
```
This is one particular solution. It depends on $Q(x)$ and contains no arbitrary
homogeneous constant.


## Are there more solutions to the linear 1st-order ODE?


:::{note}
Theorem The solution of an inhomogeneous first-order ODE is **unique** up to an arbitrary multiple of the homogeneous solution.
:::

**Proof:**

- Let $y_1$ and $y_2$ be two solutions to the inhomogeneous ODE:
```{math}
\frac{dy}{dx} + P(x) y = Q(x)
```


- This gives us two equations:
```{math}
\frac{dy_1}{dx} + P(x) y_1 = Q(x), \quad \frac{dy_2}{dx} + P(x) y_2 = Q(x)
```


- Subtracting these equations, we get:
```{math}
\frac{d}{dx} (y_1 - y_2) + P(x) (y_1 - y_2) = 0
```


## Are there more solutions to the linear 1st-order ODE? (continued)


- Therefore, the difference $y_1 - y_2$ satisfies the homogeneous equation:
```{math}
\frac{d}{dx} (y_1 - y_2) + P(x) (y_1 - y_2) = 0
```


- This proves that any two solutions of the inhomogeneous ODE differ by a solution to the homogeneous equation.

- Hence, the particular solution to the inhomogeneous equation is unique up to an arbitrary multiple of the homogeneous solution.


## Are there more solutions to the linear 1st-order ODE? (continued)


:::{note}
Theorem For a first-order homogeneous linear ODE, there exists only one linearly independent solution.
:::

**Proof**

- Let $y_1$ and $y_2$ be solutions to the homogeneous ODE:
```{math}
\frac{dy}{dx} + P(x)y = 0
```


- Then:
```{math}
\frac{dy_1}{dx} = -P(x)y_1, \quad \frac{dy_2}{dx} = -P(x)y_2
```


- The Wronskian of these solutions is:
```{math}
\begin{aligned}
  W(y_1, y_2) &= y_1y_2' - y_2y_1' \\
  &= y_1(-P(x)y_2) - y_2(-P(x)y_1) = 0
  \end{aligned}
```


- Since the Wronskian is identically zero, $y_1$ and $y_2$ must be linearly dependent.


## Recall example


:::{admonition} Example

```{math}
y' + y = e^x
```
 Here, $P(x) = 1$ and $Q(x) = e^x$.\
The solution is:
```{math}
y(x) = e^{-x} \left( \frac{1}{2} e^{2x} + C \right) = \frac{1}{2} e^x + C e^{-x}
```

:::


## Slope Fields


- To better understand the behavior of the solution to the differential equations, we can plot the **slope field** corresponding to the equation.

- For the previous example, we have:
```{math}
y' = e^x - y
```


- In the slope field plot, we represent $y$ versus $x$, and at each point $(x, y)$, the slope $y'$ is plotted to show the direction in which the solution evolves.

- This slope field allows us to visualize how different solutions to the equation evolve depending on their initial conditions.

- Arrows represent the direction and the slope $y'$ at each point $(x, y)$. The length of the arrow represents the magnitude of the slope.

## Slope Fields (continued)


- For each point $(x, y)$, the slope $y'$ tells us how the solution curve is behaving at that location.

- The general solution $y(x) = \frac{1}{2} e^x + C e^{-x}$ includes the constant $C$, which represents the family of solutions. This means for a given initial value of $x$, there are infinitely many solutions, depending on the value of $C$.

- At $x = 0$, we can see that the slope depends entirely on $C$, and the vector field helps visualize how the solution evolves for different initial conditions.

import numpy as np

x_vals = np.linspace(-2, 2, 20)

## Linear Second-Order ODEs


- *Second-order linear homogeneous ODE* in the general form:
```{math}
\frac{d^2 y}{dx^2} + P(x) \frac{dy}{dx} + Q(x) y = 0
```


- The general solution to such an equation involves two linearly independent solutions, $y_1(x)$ and $y_2(x)$. Therefore, the general solution can be expressed as:
```{math}
y(x) = c_1 y_1(x) + c_2 y_2(x)
```
 where $c_1$ and $c_2$ are constants determined by initial or boundary conditions.


## Linear Second-Order ODEs (continued)


- For an *inhomogeneous second-order ODE*, the general form is:
```{math}
\frac{d^2 y}{dx^2} + P(x) \frac{dy}{dx} + Q(x) y = F(x)
```


- $F(x)$ can be interpreted as a driving force, and the solution to the inhomogeneous equation describes how the system responds to this external influence.

- The general solution to the inhomogeneous equation consists of two parts:
```{math}
y(x) = y_h(x) + y_p(x)
```
 where $y_h(x) = c_1 y_1(x) + c_2 y_2(x)$ is the general solution to the homogeneous equation, and $y_p(x)$ is a *particular solution* that satisfies the inhomogeneous equation, accounting for the \"driving\" term $F(x)$.

- There is no universal method to find the particular solution $y_p(x)$ for every inhomogeneous ODE.

- We will explore *Laplace transform* and the *Green's function*, which provide systematic approaches to solving inhomogeneous ODEs under various conditions.


## 2nd-order linear homogeneous ODE


:::{note}
Theorem A 2nd-order linear homogeneous ODE has only two linearly independent solutions
:::

**Proof:**

- Consider a second-order linear homogeneous ordinary differential equation (ODE) in the form:
```{math}
\frac{d^2 y}{dx^2} + P(x) \frac{dy}{dx} + Q(x) y = 0
```


- Let $y_1(x)$ and $y_2(x)$ be two linearly independent solutions of this equation.

- We aim to prove that there cannot exist a third solution $y_3(x)$ that is linearly independent of $y_1(x)$ and $y_2(x)$.

- Suppose, for contradiction, that there exists a third solution $y_3(x)$ such that the set $\{ y_1(x), y_2(x), y_3(x) \}$ is linearly independent.


## 2nd-order linear homogeneous ODE (continued)


- The Wronskian of three functions $y_1(x), y_2(x), y_3(x)$ is defined as:
```{math}
W(y_1, y_2, y_3) = \begin{vmatrix}
  y_1 & y_2 & y_3 \\
  y_1' & y_2' & y_3' \\
  y_1'' & y_2'' & y_3''
  \end{vmatrix}
```


- We will show that $W(y_1, y_2, y_3) = 0$ for all $x$, which implies that $y_1, y_2, y_3$ are linearly dependent, contradicting our assumption.

- Since each $y_i(x)$ is a solution to the differential equation, they satisfy:
```{math}
y_i'' + P(x) y_i' + Q(x) y_i = 0 \quad \text{for} \quad i = 1, 2, 3
```


- Rewriting the second derivatives:
```{math}
y_i'' = -P(x) y_i' - Q(x) y_i
```


- Substitute $y_i''$ into the Wronskian:
```{math}
W(y_1, y_2, y_3) = \begin{vmatrix}
  y_1 & y_2 & y_3 \\
  y_1' & y_2' & y_3' \\
  - P y_1' - Q y_1 & - P y_2' - Q y_2 & - P y_3' - Q y_3
  \end{vmatrix}
```


## 2nd-order linear homogeneous ODE (continued)


- Factor out $-1$ from the third row:
```{math}
W(y_1, y_2, y_3) = -\begin{vmatrix}
  y_1 & y_2 & y_3 \\
  y_1' & y_2' & y_3' \\
  P y_1' + Q y_1 & P y_2' + Q y_2 & P y_3' + Q y_3
  \end{vmatrix}
```


- Now, notice that the third row is a linear combination of the first and second rows:
```{math}
P \times \text{(Second Row)} + Q \times \text{(First Row)} = \text{Third Row}
```


- This means that the three rows are linearly dependent, and therefore, the determinant of the matrix (the Wronskian) is zero:
```{math}
W(y_1, y_2, y_3) = 0
```


- A zero Wronskian alone would not prove dependence for arbitrary
  differentiable functions. Here the conclusion follows from the existence and
  uniqueness theorem: a solution is determined by the two initial values
  $(y(x_0),y'(x_0))$. Therefore the solution space has dimension two, and every
  third solution is a linear combination of a fundamental pair.


## Finding the Homogeneous Solutions


- Unlike first-order linear ODEs, there is no general method for solving second-order linear ODEs with variable coefficients.

- Many important equations that arise in physics and engineering fall into special categories, such as Bessel's equation, Legendre's equation, or Laguerre's equation.

- These special cases often lead to solutions involving special functions, which we will consider later.

- Here, we only look at the case of constant coefficients.


## Characteristic Equation Method for Constant Coefficients


- When $P(x)$ and $Q(x)$ are constants, the characteristic equation method can be used. This method is based on the observation that exponential functions often appear as solutions to linear differential equations with constant coefficients. The derivative of an exponential function is proportional to the function itself, which aligns with the structure of linear differential equations.

- Consider the equation:
```{math}
\frac{d^2 y}{dx^2} + a \frac{dy}{dx} + b y = 0
```
 where $a$ and $b$ are constants.

- Assume an exponential solution of the form:
```{math}
y(x) = e^{r x}
```


- Substitute this solution into the differential equation:
```{math}
r^2 e^{r x} + a r e^{r x} + b e^{r x} = 0
```


## Characteristic Equation Method for Constant Coefficients (continued)


```{math}
r^2 e^{r x} + a r e^{r x} + b e^{r x} = 0
```


- Simplify by dividing both sides by $e^{r x}$ (since $e^{r x} \neq 0$):
```{math}
r^2 + a r + b = 0
```
 This is the *characteristic equation*.

- Solve the characteristic equation for the two solutions $r_1$ and $r_2$. These coefficients can, in general, be complex. For the case that the two roots are distinct,
```{math}
y(x) = c_1 e^{r_1 x} + c_2 e^{r_2 x}
```


- However, if the roots are degenerate, ($r_1 = r_2 = r$):
```{math}
y(x) = (c_1 + c_2 x) e^{r x}
```


## Example: Solving with Constant Coefficients


- Consider the equation:
```{math}
\frac{d^2 y}{dx^2} - 3 \frac{dy}{dx} + 2 y = 0
```


- The characteristic equation is:
```{math}
r^2 - 3 r + 2 = 0 \implies (r - 1)(r - 2) = 0
```


- The roots are $r_1 = 1$ and $r_2 = 2$. Therefore, the general solution is:
```{math}
y(x) = c_1 e^{x} + c_2 e^{2 x}
```


- The coefficients $c_1$ and $c_2$ are determined by two boundary conditions. For example, if we are given $y(0) = 0$ and $y'(0)=0$, then we can solve for $c_1$ and $c_2$.


## Example: Damped Harmonic Oscillator


- The damped harmonic oscillator is a fundamental example in physics and engineering, governed by the equation:
```{math}
m \frac{d^2 y}{dt^2} + b \frac{dy}{dt} + k y = 0
```
 $m$ is the mass, $b$ is the damping coefficient, and $k$ is the spring constant.

- Dividing through by $m$ and introducing the parameters $\omega_0^2 = \dfrac{k}{m}$ (the natural frequency) and $\gamma = \dfrac{b}{2m}$ (the damping coefficient per unit mass), we can rewrite the equation as:
```{math}
\frac{d^2 y}{dt^2} + 2 \gamma \frac{dy}{dt} + \omega_0^2 y = 0
```


- The characteristic equation associated with this differential equation is:
```{math}
r^2 + 2 \gamma r + \omega_0^2 = 0
```


## Example: Damped Harmonic Oscillator (continued)


```{math}
r^2 + 2 \gamma r + \omega_0^2 = 0
```
\
Solving for $r$:
```{math}
r = -\gamma \pm \sqrt{\gamma^2 - \omega_0^2}
```


The nature of the roots depends on the discriminant $\Delta = \gamma^2 - \omega_0^2$, which leads to three distinct cases:

- **Underdamped ($\gamma^2 < \omega_0^2$)**\

- **Critically Damped ($\gamma^2 = \omega_0^2$)**\

- **Overdamped ($\gamma^2 > \omega_0^2$)**\


## Underdamped case


```{math}
r = -\gamma \pm \sqrt{\gamma^2 - \omega_0^2}
```


**Underdamped ($\gamma^2 < \omega_0^2$)**:

- \
  The roots are complex conjugates, $r = -\gamma \pm i \omega_d$, where $\omega_d = \sqrt{\omega_0^2 - \gamma^2}$ is the damped frequency.

- The solution is:
```{math}
y(t) = e^{-\gamma t} \left[ c_1 \cos(\omega_d t) + c_2 \sin(\omega_d t) \right]
```


- This describes oscillatory motion with an exponentially decaying amplitude. The system continues to oscillate, but the amplitude gradually decreases due to the damping. This behavior is common in systems where the damping is not strong enough to stop the oscillations immediately.


## Critically Damped case


```{math}
r = -\gamma \pm \sqrt{\gamma^2 - \omega_0^2}
```
 **Critically Damped ($\gamma^2 = \omega_0^2$)**:\

- The roots are repeated real roots, $r = -\gamma$.

- The solution is:
```{math}
y(t) = (c_1 + c_2 t) e^{-\gamma t}
```


- This describes a system that returns to equilibrium as quickly as possible without oscillating. Critical damping is often desired in practical applications, such as in shock absorbers or door closers, where the goal is to minimize oscillation and achieve a quick return to rest.


## Overdamped case


```{math}
r = -\gamma \pm \sqrt{\gamma^2 - \omega_0^2}
```
 **Overdamped ($\gamma^2 > \omega_0^2$)**:\

- The roots are distinct real numbers, $r = -\gamma \pm \sqrt{\gamma^2 - \omega_0^2}$.

- The solution is:
```{math}
y(t) = c_1 e^{r_1 t} + c_2 e^{r_2 t}
```
 where $r_1$ and $r_2$ are both negative.

- In this case, the system returns to equilibrium without oscillating, but more slowly than in the critically damped scenario. The motion is sluggish, and the system takes a longer time to reach rest.


## Finding one homogeneous solution from another


- While we aren't able to find a general solution for the 2nd order ODE like we did for the 1st order ODE, there is one useful identity.

- If we know one linearly independent homogeneous solution, we can always use it to find the second.

- Namely, if one solution $y_1(x)$ is known, a second linearly independent solution can be found using:
```{math}
y_2(x) = y_1(x) \int \frac{e^{ - \int P(x) dx }}{ \left[ y_1(x) \right]^2 } dx
```


## Laplace Transform

The Laplace transform is a systematic method for solving linear differential
equations with initial conditions and time-dependent inputs.


## Fourier vs Laplace transform


- The Fourier Transform excels in the frequency domain, where time derivatives become algebraic operations, making it useful for analyzing steady-state oscillations and periodic signals.

- One might wonder: why use the Laplace Transform instead of the Fourier Transform?

- While both transforms convert functions from the time domain to another
  domain (the complex $p$-plane for Laplace and real angular frequency
  $\omega$ for Fourier), they serve different purposes.

- Fourier Transform is Ideal for analyzing steady-state signals and oscillations over an infinite time period.

- Laplace Transform is better suited for systems with transient behaviors, especially those driven by initial conditions or time-dependent inputs.


## Fourier vs Laplace transform (continued)


- In this lecture we use the *one-sided* Laplace transform, integrating from
  $0$ to $\infty$, which naturally exposes initial values when derivatives are
  transformed. Bilateral Laplace transforms also exist. The Fourier transform
  used earlier integrates over the entire real line.

- Thus, for solving ODEs with initial conditions and transient signals, the Laplace Transform is the preferred method, while the Fourier Transform is better suited for steady-state, oscillatory behavior.

- The complex Laplace variable also describes exponential growth or decay
  through its real part and oscillation through its imaginary part.

- The Laplace Transform is a **linear operator**, meaning it satisfies the following properties:
```{math}
\mathcal{L}\{f(t) + g(t)\} = \mathcal{L}\{f(t)\} + \mathcal{L}\{g(t)\}
```

```{math}
\mathcal{L}\{cf(t)\} = c \mathcal{L}\{f(t)\}
```


## Laplace Transform of Derivatives


- Consider the Laplace transform of the first derivative $f'(t)$:
```{math}
\mathcal{L}\{f'(t)\} = \int_0^\infty e^{-pt} f'(t) \, dt
```


- To evaluate this integral, we use integration by parts. Let:
```{math}
u = e^{-pt}, \quad dv = f'(t) \, dt
```

```{math}
du = -p e^{-pt} \, dt, \quad v = f(t)
```


- Applying integration by parts:
```{math}
\mathcal{L}\{f'(t)\} = \left[ e^{-pt} f(t) \right]_0^\infty + p \int_0^\infty e^{-pt} f(t) \, dt
```


- Assuming that $f(t)$ does not grow faster than an exponential function as $t \to \infty$ (so that $e^{-pt} f(t) \to 0$ as $t \to \infty$):
```{math}
\mathcal{L}\{f'(t)\} = 0 - f(0) + p F(p) = p \mathcal{L}\{f(t)\} - f(0)
```


- Thus, the Laplace transform of the first derivative is:
```{math}
\mathcal{L}\{f'(t)\} = p \mathcal{L}\{f(t)\} - f(0)
```


## Laplace transforms of function derivatives


:::{admonition} Center
   **Function**            **Laplace Transform**
  -------------- ------------------------------------------
      $f(t)$                       $F(p)$
     $f'(t)$                   $pF(p) - f(0)$
     $f''(t)$           $p^2 F(p) - p f(0) - f'(0)$
    $f'''(t)$     $p^3 F(p) - p^2 f(0) - p f'(0) - f''(0)$
:::


## Laplace transform of common functions


As an example, let's calculate the Laplace transform of $f(t) = e^{-at}$.

The Laplace Transform is:
```{math}
F(p) = \int_0^\infty e^{-(a+p)t} dt = \frac{1}{p + a}, \quad \text{for } \Re(p + a) > 0
```


## Laplace transform of common functions (continued)


:::{admonition} Center
         **Function** $f(t)$                    **Laplace Transform** $F(p)$
  ---------------------------------- ---------------------------------------------------
                 $1$                                    $\frac{1}{p}$
                 $t$                                   $\frac{1}{p^2}$
                $t^n$                               $\frac{n!}{p^{n+1}}$
               $e^{at}$                        $\frac{1}{p - a}$, $\Re(p) > a$
              $\sin(bt)$                            $\frac{b}{p^2 + b^2}$
              $\cos(bt)$                            $\frac{p}{p^2 + b^2}$
             $\sinh(bt)$                    $\frac{b}{p^2 - b^2}$, $\Re(p) > |b|$
             $\cosh(bt)$                    $\frac{p}{p^2 - b^2}$, $\Re(p) > |b|$
              $t e^{at}$                     $\frac{1}{(p - a)^2}$, $\Re(p) > a$
             $t^n e^{at}$                 $\frac{n!}{(p - a)^{n+1}}$, $\Re(p) > a$
          $e^{at} \sin(bt)$               $\frac{b}{(p - a)^2 + b^2}$, $\Re(p) > a$
          $e^{at} \cos(bt)$             $\frac{p - a}{(p - a)^2 + b^2}$, $\Re(p) > a$
             $t \sin(bt)$                       $\frac{2b p}{(p^2 + b^2)^2}$
             $t \cos(bt)$                     $\frac{p^2 - b^2}{(p^2 + b^2)^2}$
            $t^2 \sin(bt)$                 $\frac{2b(3p^2 - b^2)}{(p^2 + b^2)^3}$
            $t^2 \cos(bt)$                 $\frac{2p(p^2 - 3b^2)}{(p^2 + b^2)^3}$
             $\delta(t)$                                     $1$
           $\delta(t - a)$                           $e^{-a p}$, $a > 0$
           $\delta'(t - a)$                              $p e^{-a p}$
          $\delta''(t - a)$                            $p^2 e^{-a p}$
   $H(t)$ (Heaviside Step Function)                     $\frac{1}{p}$
              $H(t - a)$                        $\frac{e^{-a p}}{p}$, $a > 0$
            $e^{at} H(t)$                      $\frac{1}{p - a}$, $\Re(p) > a$
             $t H(t - a)$               $\frac{e^{-a p}}{p^2} + \frac{a e^{-a p}}{p}$
         $e^{at} t \sin(bt)$               $\frac{2b(p - a)}{[(p - a)^2 + b^2]^2}$
         $e^{at} t \cos(bt)$            $\frac{(p - a)^2 - b^2}{[(p - a)^2 + b^2]^2}$
:::

The general shift theorem is safer than memorizing specialized rows:
```{math}
\mathcal{L}\{H(t-a)f(t-a)\}
=e^{-ap}F(p),
\qquad
F(p)=\mathcal{L}\{f(t)\}.
```


## Example: Solving an ODE Using Laplace Transforms


- Consider the differential equation:
```{math}
y'' + 4y' + 4y = t^2 e^{-2t}
```
 with initial conditions:
```{math}
y(0) = 0, \quad y'(0) = 0
```


- Recall the Laplace transform of derivatives:
```{math}
\mathcal{L}\{y''\} = p^2 F(p) - p y(0) - y'(0)
```

```{math}
\mathcal{L}\{y'\} = pF(p) - y(0)
```


- Take the Laplace Transform of both sides:
```{math}
p^2 F(p) - p y(0) - y'(0) + 4p F(p) - 4 y(0) + 4F(p)= \mathcal{L}\{t^2 e^{-2t}\}
```


- Given that $y(0) = 0$ and $y'(0) = 0$, we simplify to:
```{math}
F(p) = \frac{2}{(p+2)^5}
```


## Example: Solving an ODE Using Laplace Transforms (continued)


```{math}
y'' + 4y' + 4y = t^2 e^{-2t}
```

```{math}
F(p) = \frac{2}{(p+2)^5}
```


- Taking the inverse Laplace transform using the table returns to the time
  domain:
```{math}
y(t) = \frac{t^4 e^{-2t}}{12}
```


- This example illustrates how the Laplace Transform converts a complex differential equation into an algebraic one, simplifying the process of finding a solution.
