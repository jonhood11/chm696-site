# Computational notebooks

These executable MyST pages connect the analytical course material to Python.
Every result is recomputed when the website is built, so a failed calculation
also fails the course-site build.

- [Series and complex numbers](series-and-complex.md)
- [Linear algebra](linear-algebra.md)
- [Optimization and SVD](optimization-and-svd.md)
- [Fourier analysis](fourier-analysis.md)
- [Differential equations](differential-equations.md)
- [Complex analysis](complex-analysis.md)
- [Monte Carlo and Markov processes](monte-carlo.md)
- [Machine learning](machine-learning.md)

The browser displays the computed figures without requiring students to install
Python. Curated in-browser exercises can later be added as a separate
JupyterLite laboratory.
